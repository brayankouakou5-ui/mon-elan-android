# mon-elan-android
Mon Élan est une application Android simple et pratique de suivi des habitudes quotidiennes. Elle permet d'ajouter, de modifier et de supprimer des habitudes, de suivre sa progression, de consulter son historique et de mesurer ses séries de jours consécutifs. L'application fonctionne hors ligne et conserve les données directement sur le téléphone.
